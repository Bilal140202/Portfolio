# Portfolio - AI Build Blueprint

This repository contains a premium, high-performance developer portfolio framework designed to showcase technical expertise through a sleek, modern interface.

## Goal
To provide a highly customizable and visually stunning portfolio template that prioritizes performance, SEO, and a premium user experience.

## Tech Stack
- **Framework:** Likely Next.js or Vite (to be initialized).
- **Styling:** Tailwind CSS / Vanilla CSS.
- **Animations:** Framer Motion or GSAP.
- **Data:** Markdown-based project tracking or Headless CMS integration.

## AI Guidelines
1. Prioritize "Visual Impact" and "Professionalism" in all UI/UX decisions.
2. Ensure the portfolio is fully responsive and optimized for mobile-first experiences.
3. Follow the \.ai_build_plan.md\ for architectural context.
4. Maintain high SEO scores through proper use of semantic HTML and meta tags.
5. All project showcases should include high-quality images and detailed technical descriptions.
